# research/generative — generative-art factory records

Records from the generative-visuals factory that expanded `assets/visual/genart/`
from 34 → 166 pieces. **For how to USE / author / extend the p5 visual system, start
at [`.claude/skills/p5.md`](../../.claude/skills/p5.md)** — these files are the run
history and the durable findings behind it.

| File | What it is |
|---|---|
| `FINAL_REPORT.md` | **Outcome** — what's in the catalog, coverage by generative family, ranked self-grades, known-minor list, second-pass brief. Read this to know what exists. |
| `FACTORY_STATE.md` | **Resume runbook** — the loop, infra bring-up, and the full list of hard-won learnings (motion re-phasing, dead-space, quota pacing, param false-pass). The `>>> RESUME HERE <<<` block is the live checkpoint. |
| `COVERAGE.md` | Per-family checklist of planned vs done generative techniques. |
| `PROBE.md` | Engine capability/perf probe (what the p5-2D canvas can sustain). |
| `RESUME_PROMPT.md` | The onboarding prompt used to (re)start a factory session. |
| `TASTE.md` | (created when grades come in) Gene's bad/ok/good verdicts + inferred aesthetic preferences, to bias future authoring. |

Tooling that produced these lives in `scratchpad/gf/` (gf_snap.py, gf_sheet.py,
author_workflow.js, `ref/*.js` proven kernels, `wave*.json` batch specs).
