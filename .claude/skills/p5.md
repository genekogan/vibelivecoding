# p5.js Live Coding — Agent Guide

## What This Is

A Python-to-browser system for AI-driven live-coded visuals. You write Python scripts that send p5.js drawing code over WebSocket to a browser running a full-screen canvas. The browser compiles each layer into a function and calls it every frame.

**p5.js** is a JavaScript creative coding library. We use it in global mode — all p5 functions (`circle()`, `fill()`, `background()`, etc.) are available as globals.

## Architecture

```
Python script (your_visuals.py)
  └─→ P5Controller (p5_server.py)
        ├─→ WebSocket server (ws://localhost:8775)
        │     └─→ p5.html (browser client)
        │           └─→ p5.js 1.11.11 canvas + layer system
        └─→ HTTP file server (http://localhost:8776)
              └─→ serves p5.html + static files
```

Optional add-ons:
- `p5_live.py` — HTTP REST API on port 8777 for external control
- `p5_send.py` — One-shot CLI to send code without a Python script

## How to Use It

### Quick Start

```python
from p5_server import P5Controller
import time

ctrl = P5Controller()
ctrl.start()
# User opens http://localhost:8776/p5.html and clicks "Start & Connect"
ctrl.wait_for_browser()

# Set layers
ctrl.set_layer("bg", "background(0);")
ctrl.set_layer("shape", """
    fill(255, 0, 0);
    circle(width/2, height/2, 200 + sin(frameCount * 0.05) * 50);
""")

time.sleep(5)

# Update just the background — shape layer keeps running untouched
ctrl.set_layer("bg", "background(20, 0, 40);")

# Remove one layer
ctrl.remove_layer("shape")

# Clear everything
ctrl.clear()
```

### Sending Code Without a Script

```bash
# CLI (fastest for agent use)
python p5_send.py --layer bg 'background(0);'
python p5_send.py --layer shape 'fill(255,0,0); circle(width/2, height/2, 200);'
python p5_send.py --remove shape
python p5_send.py --clear
python p5_send.py 'state.hue = 180'    # plain eval

# REST API (if p5_live.py is running)
curl -X POST localhost:8777/layer -d '{"name":"bg","code":"background(0);"}'
curl -X POST localhost:8777/remove -d '{"name":"shape"}'
curl -X POST localhost:8777/clear
curl localhost:8777/status
```

### Python API Reference

| Method | Description |
|--------|-------------|
| `ctrl.start()` | Start WebSocket + HTTP servers |
| `ctrl.wait_for_browser(timeout=30)` | Block until browser connects |
| `ctrl.send(code, mode="eval")` | Send raw JS to browser |
| `ctrl.set_layer(name, code)` | Set/update a named drawing layer |
| `ctrl.remove_layer(name)` | Remove a layer |
| `ctrl.clear()` | Remove all layers, blank canvas |
| `ctrl.set_setup(code)` | Hard recompile — new setup(), preserves state+layers |
| `ctrl.set_canvas(w, h)` | Resize canvas |
| `ctrl.set_state(key, value)` | Set a key in `window.state` |
| `ctrl.init_state(**kwargs)` | Set keys only if not already defined |
| `ctrl.set_fps(fps)` | Set target frame rate |
| `ctrl.set_background(*args)` | Convenience: sets a `__bg` layer |
| `ctrl.layers` | Dict of current layer code |
| `ctrl.close()` | Shut down servers |

## Key Concepts

### Layers (not tracks)

Strudel combines tracks via `stack().play()` — updating one track replays all. p5.js layers are **independent**: updating one layer does NOT touch others. The draw loop iterates the layer Map every frame.

```python
ctrl.set_layer("bg", "background(0);")
ctrl.set_layer("circles", "fill(255,0,0); circle(width/2, height/2, 200);")
ctrl.set_layer("text", "fill(255); textSize(20); text('hello', 20, 40);")
```

Each layer gets automatic `push()`/`pop()` wrapping — transforms, styles, and matrix state are isolated per layer.

### Persistent State

`window.state = {}` survives all layer updates. Use it for animation state, particle systems, anything that accumulates over time.

```python
ctrl.init_state(particles=[], hue=0)
ctrl.set_layer("particles", """
    state.particles.push({x: random(width), y: random(height)});
    if (state.particles.length > 200) state.particles.shift();
    noStroke();
    for (let p of state.particles) {
        fill(state.hue, 80, 90, 50);
        circle(p.x, p.y, 5);
    }
""")
```

### Soft vs Hard Compile

- **Soft** (default): `set_layer()`, `remove_layer()` — only the targeted layer function is replaced. `frameCount`, `state`, canvas all survive.
- **Hard** (`set_setup()`): destroys p5 instance, recreates with new `setup()`, restores state and layers. Use for canvas size/mode changes.

### Error Handling

- Syntax errors in `new Function(code)` → layer is NOT updated, old function keeps running, error sent back to Python.
- Runtime errors inside `draw()` → caught per-layer with `try/catch`, throttled to 1 log per second per layer. Other layers keep running.

## Writing Visuals That Look Amazing

### The Golden Rules

**1. Use `frameCount` for Animation**
Everything animates via `frameCount`. Use `sin(frameCount * speed)` for oscillation, `frameCount % period` for cycling, `frameCount * speed` for rotation.

```javascript
// Pulsing circle
let size = 200 + sin(frameCount * 0.05) * 80;
circle(width/2, height/2, size);
```

**2. HSB Color Mode**
Always work in HSB for vivid, cycling colors. The canvas defaults to `colorMode(HSB, 360, 100, 100, 100)`.

```javascript
// Rainbow cycling
fill((frameCount * 2) % 360, 80, 90);
```

**3. Layer Composition**
Build scenes from independent layers. Background first, then shapes, then foreground effects. Each layer should do one thing well.

```python
ctrl.set_layer("bg", "background(0, 0, 10);")          # dark base
ctrl.set_layer("shapes", "fill(200, 80, 90); ...")      # main content
ctrl.set_layer("fx", "noStroke(); ...")                  # sparkles, particles
ctrl.set_layer("ui", "fill(0,0,100); text(...); ...")    # text overlay
```

**4. Use `state` for Accumulation**
Particles, trails, history — anything that builds up over time goes in `state`.

**5. Trails via Semi-Transparent Background**
Instead of `background(0)` (hard clear), use `background(0, 0, 0, 10)` (semi-transparent) for motion trails.

**6. `translate()` + `rotate()` for Complex Shapes**
Build shapes at the origin, then position with transforms. `push()`/`pop()` is automatic per layer, but use it inside layers for sub-transforms.

### Common Patterns

**Oscillation:** `sin(frameCount * speed) * amplitude`
**Rotation:** `rotate(frameCount * speed)`
**Color cycling:** `(frameCount * speed) % 360` as hue
**Noise:** `noise(x * scale, y * scale, frameCount * speed)`
**Lissajous:** `sin(t * a)` for x, `cos(t * b)` for y
**Pulsing:** `map(sin(frameCount * 0.05), -1, 1, minVal, maxVal)`
**Easing:** `lerp(current, target, 0.05)` for smooth transitions

### Visual Recipes

**Particle System:**
```javascript
if (!state.ps) state.ps = [];
state.ps.push({x: random(width), y: height, vy: random(-3, -1), life: 255});
for (let i = state.ps.length-1; i >= 0; i--) {
    let p = state.ps[i];
    p.y += p.vy; p.life -= 2;
    if (p.life <= 0) { state.ps.splice(i, 1); continue; }
    fill(200, 80, 90, p.life/255*100);
    circle(p.x, p.y, map(p.life, 0, 255, 1, 8));
}
```

**Hypnotic Spirals:**
```javascript
translate(width/2, height/2);
noFill(); strokeWeight(2);
for (let i = 0; i < 200; i++) {
    let a = i * 0.1 + frameCount * 0.02;
    let r = i * 2;
    stroke((i * 3 + frameCount) % 360, 80, 90, 60);
    point(cos(a) * r, sin(a) * r);
}
```

**Warped Grid:**
```javascript
noFill(); strokeWeight(0.5);
for (let x = 0; x < width; x += 20) {
    for (let y = 0; y < height; y += 20) {
        let d = dist(x, y, mouseX, mouseY);
        let offset = sin(d * 0.02 - frameCount * 0.05) * 15;
        stroke((d + frameCount) % 360, 70, 90, 50);
        point(x + offset, y + offset);
    }
}
```

**Kaleidoscope:**
```javascript
translate(width/2, height/2);
let segments = 8;
for (let s = 0; s < segments; s++) {
    push();
    rotate(TWO_PI / segments * s);
    // Draw your shape here — it mirrors around center
    fill((frameCount + s * 45) % 360, 80, 90, 40);
    let x = sin(frameCount * 0.03) * 100;
    let y = cos(frameCount * 0.04) * 80;
    circle(x, y, 30);
    pop();
}
```
