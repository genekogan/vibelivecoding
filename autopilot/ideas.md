# Visual ideas pool

reorder, star favorites. The loop should **scan this file** when picking a
fresh concept (in addition to the journal-tail dedupe).

Format hint: one idea per bullet, short — the agent's job is to develop the
prompt into a real scene. Optional suggested genre in parens.
